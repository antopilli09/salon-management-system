Web-based salon management system developed with HTML, CSS, JavaScript and Firebase.

## Features

- Client management
- Appointment scheduling
- Calendar management
- Expense management and tracking
- Cloud database integration

## Technologies

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Firestore Database
- Firebase Hosting

## Overview

This project was developed as a complete salon management solution, allowing businesses to manage clients, appointments and expenses through a cloud-based platform.
